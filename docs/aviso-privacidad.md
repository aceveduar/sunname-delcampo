## 1. ¿Qué datos personales tratamos?

Sunname ERP es un sistema de gestión (ERP + punto de venta) que cada negocio cliente ("el Negocio") usa para operar su propia tienda o consultorio. A través del Sistema se tratan dos tipos de datos:

**a) Datos de las personas que operan el Sistema** (dueños, administradores, cajeros del Negocio):
- Nombre completo, correo electrónico, rol dentro del Sistema.

**b) Datos de los clientes finales del Negocio**, capturados por el Negocio dentro del módulo de Clientes (CRM), únicamente si el Negocio decide registrarlos:
- Nombre, teléfono, correo electrónico, notas asociadas a su relación comercial con el Negocio.

Sunname ERP **no recaba estos datos directamente de los clientes finales** — los captura el Negocio (por ejemplo, Del Campo) como parte de su propia operación. Frente a esos datos, Sunname ERP actúa como **Encargado** (procesa los datos por cuenta del Negocio, que es quien decide para qué los usa), y el Negocio es el **Responsable** frente a sus propios clientes.

## 2. Finalidades del tratamiento

**Finalidades primarias** (necesarias para operar el Sistema):
- Dar acceso al Sistema a las personas autorizadas por cada Negocio.
- Registrar ventas, inventario, compras y la relación comercial de cada Negocio con sus propios clientes.
- Generar reportes operativos para el Negocio.

## 3. Transferencia de datos

Los datos se almacenan en la infraestructura de **Supabase** (proveedor de base de datos e infraestructura en la nube, con servidores fuera de México — ver CLAUDE.md §8), estrictamente para la operación técnica del Sistema. No se venden ni se comparten con terceros para fines distintos a operar el Sistema.

## 4. Derechos ARCO

Cualquier persona cuyos datos estén en el Sistema (empleado de un Negocio, o cliente final de un Negocio) puede ejercer sus derechos de **A**cceso, **R**ectificación, **C**ancelación u **O**posición:

- Si es empleado/usuario del Sistema: contactando directamente al Negocio donde trabaja, o a `[correo de contacto de Sunname]`.
- Si es cliente final de un Negocio (ej. cliente de Del Campo): contactando directamente a ese Negocio, quien es el responsable de sus datos.
